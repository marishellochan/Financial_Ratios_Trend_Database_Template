This Excel Database was made by me during my Summer Job at a Bank. I created this Excel database with Macros that can be customized to suit 
the relevant requirments of a business or company. This Database shows the Financial Ratios and its Trends of a particular Company/Business.
A form sheet must be filled out in order to create the database to be relevant to the business. 
Once the form is filled out and the button is clicked, the database is customized. 
Ratio data added during each quarter of the year is added and one can see if the company meets the requirement or not based on the color of the cell.
Once one year's data is entered, a sheet is created when the "Create New Year Trend" button is clicked which shows the averages and trends of each ratio for the 
quarters of that particular year. 
The "Yearly Trends" sheets shows the overall average of ratio each year on graphs. 
This template can be resetted and can be used for customization. 

How to Use the Financial Ratios Database Template
Read Instructions 
Start by reading these instructions to understand how to use the template effectively.
1.Fill Out the Form Sheet
Go to the sheet labeled "Form" and fill out the following questions:
Business name
Number of ratios received
Number of statements (maximum of 5 ratios)
Ratio information (names and equations)
2. Create Database
Fill out all the required information in the form.
Click on the "Create" button to generate the database.
3. Navigate to F.Ratios Data Sheet
Move to the F.Ratios Data sheet to input data for each quarter (March, June, September, December) for ONE year at a time.
4. Implement Data
Enter the financial ratios data for each quarter.
Data that meets the requirement turns green, while data that doesn't meet the requirement turns red.
5. Create New Year Trend Sheet for the "latest" year entered
After inputting data for a ONE full year, click on the "Create New Year Trend" button to generate a trend sheet for the LAST row of data..
6. Update Yearly Trends
Once the 'Create New Year Trend' button is clicked, it also updates the "F.Ratios yearly trends" sheet which displays averages and trends for each ratio over the years.
7. Make Corrections (This is only if mistakes were made in the Last year added)
If you need to make corrections for the last year added:
Delete the Trend sheet for that year.
Delete the data of that particular year on the "F.Ratios Yearly Trends" Sheet, such as the Year and Average 
Adjust the data in the F.Ratios Data sheet.
Then Click Create New year trend sheet and everything should be updated
If the correction is to be made for a year prior, you may have to reset the database and start over. SO MAKE SURE AND CHECK OVER FIRST BEFORE PROCEEDING TO OTHER YEARS!
8. Resetting the Database 
If you need to start over or make significant changes:
Click on the "Reset" button on the Form sheet to clear all data.
9. Final Tips
Avoid touching template sheets or merging cells to ensure the smooth functioning of the database!
If needed, start fresh with a new template sheet instead of resetting.
